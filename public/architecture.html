Technology stack
Stack decisions & rationale
⚡
Next.js 16
Full-stack framework
App Router + Turbopack
Server components eliminate client round-trips for data fetching. Turbopack cuts local rebuild to <400ms. Single codebase for UI and API.
🤖
Anthropic Claude
AI engine
claude-sonnet-4-6
Best-in-class reasoning for salary analysis and psychometric assessment. Structured JSON outputs with Zod validation. Prompt injection protection on all routes.
🗄️
Supabase
Backend as a service
PostgreSQL + RLS
Managed auth, database, and file storage. Row-Level Security enforces data isolation at DB level — no user can access another's data regardless of application bugs.
🚀
Vercel
Deployment & CDN
Edge + Serverless
Zero-config deployments from Git. Global CDN with edge functions. Preview deployments on every PR. 60s function timeout for AI routes.
💳
Razorpay
Payments
India-native
India's leading payment gateway. Supports UPI, cards, netbanking. Webhook-verified credit top-ups. No card data stored on EarnGro servers.
🔷
TypeScript + Zod
Type safety
Strict mode
TypeScript strict mode throughout. Zod validates every AI response — a malformed Claude output throws before touching the database, never silently corrupts data.
Data flow
AI feature request lifecycle
How a GrowDNA assessment travels from user input to scored result — the same pattern applies to CV analysis and interview sessions.
1
Auth check
Middleware verifies Supabase session. Unauthenticated requests redirected to login.
proxy.ts
2
Credit gate
Atomic SQL function checks + deducts credits. Race-condition safe. Returns 402 if insufficient.
deduct_credits()
3
Prompt build
User data injected into typed prompt template. Anti-injection preamble prepended. Safety rules enforced.
lib/ai/prompts/
4
Claude API
Single client instance calls Anthropic. Retries up to 3× with prompt hardening on parse failures.
callAIJSONWithRetry()
5
Zod validate
AI response parsed and validated against typed schema. Invalid shapes throw — never reach DB.
ATSResultSchema
6
Persist + respond
Validated result written to Supabase. Credits logged. Response returned to client with balance.
supabase.from()

Scale readiness
Built to scale
⚡
Serverless-first
Zero server management. Vercel auto-scales API functions to demand. No cold-start penalty for authenticated routes.
🔄
Async parse pipeline
CV parsing runs async with client polling. No request timeout risk. PDF → OCR fallback chain handles all resume types.
🛡️
Abuse-resistant
Credit system caps AI cost per user. Atomic SQL prevents race conditions. IP rate limiting on anonymous routes.
🏗️
Clean separation
Services → Repositories → Routes architecture. AI layer isolated in lib/ai/. Any component replaceable independently.
📊
Observability ready
Credit transaction log provides full audit trail. Token usage trackable per feature. Sentry error monitoring integrated.
🔮
Roadmap-ready
Schema supports job matching (pgvector), recruiter analytics, resume embeddings, and B2B employer dashboard as next layers.
